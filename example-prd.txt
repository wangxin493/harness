一、产品PRD（完整最终需求）
1. 产品概述
本产品是一款纯前端、无登录、轻量化网页笔记工具，基于浏览器本地存储实现所有数据持久化，无需后端服务、无需注册登录，开箱即用。支持笔记创建、置顶、归档、删除、分类页面管理，界面极简，专注快速临时记录场景。

2. 核心规则
- 全程无登录、无鉴权、无用户体系
- 所有数据存储在浏览器 localStorage，刷新页面不丢失，清除浏览器缓存数据会丢失
- 仅适配PC端，不做移动端适配
- 所有操作实时持久化保存

3. 技术栈约束（必须严格遵守）
- 前端框架：React 18
- 开发语言：TypeScript（禁止使用 any 滥用）
- UI 组件库：Ant Design 5.x（简称 antd）
- 构建工具：Webpack 5
- 路由：React Router v6
- 状态管理：React Context + 自定义 Hooks（禁止 Redux、Zustand、Mobx）
- 样式方案：基于 Ant Design 内置样式，少量全局样式
- 富文本编辑器：TipTap（@tiptap/react）
- 禁止接入任何后端接口、网络请求、登录注册
- 禁止移动端适配，只做 PC 端
- 禁止复杂动画、多余 UI 效果、广告弹窗

4. 路由设计
| 路由 | 组件 | 功能 |
|------|------|------|
| `/` | NoteList | 展示所有未归档笔记 |
| `/note/new` | NoteEditor | 新建笔记页面 |
| `/note/:id` | NoteEditor | 编辑笔记页面 |
| `/archive` | NoteList (type=archive) | 展示所有已归档笔记 |

5. 页面功能需求

5.1 公共页面结构（首页+归档页统一）
- 顶部导航：产品名称 + 首页/归档页 切换导航
- 页面顶部：创建笔记主按钮
- 主体区域：笔记卡片列表
- 每条笔记卡片右侧：编辑按钮 + 三点更多操作菜单
- 空状态展示对应空文案
- 底部展示本地存储风险提示小字

5.2 首页功能（/）
- 只展示：未归档的有效笔记
- 排序规则：置顶笔记优先置顶展示，其余按创建时间倒序
- 置顶笔记卡片显示「置顶」标签
- 卡片操作：点击编辑进入 /note/:id，点击更多菜单：置顶/取消置顶、归档、删除

5.3 归档页功能（/archive）
- 只展示：已归档笔记
- 不支持置顶功能，不展示置顶标签
- 卡片操作：点击编辑进入 /note/:id，点击更多菜单：取消归档、删除

5.4 编辑页面（/note/new 和 /note/:id）

布局结构：
```
┌─────────────────────────────────────────┐
│ [← 返回]    编辑笔记       [保存]       │  ← 顶部栏
├─────────────────────────────────────────┤
│                                         │
│     富文本编辑器区域                     │
│     - 支持加粗、无序列表、有序列表、删除线 │
│                                         │
├─────────────────────────────────────────┤
│ 工具栏：加粗 | 无序列表 | 有序列表 | 删除线 │
└─────────────────────────────────────────┘
```

6. 核心功能详细规则

6.1 创建笔记
- 点击创建笔记按钮，跳转至 /note/new 页面
- 页面加载空白富文本编辑器
- 禁止空内容保存
- 新建笔记默认状态：未置顶、未归档、生成唯一ID、携带创建时间戳
- 点击保存后返回首页

6.2 编辑笔记
- 点击笔记卡片编辑按钮，跳转至 /note/:id 页面
- 页面加载该笔记的富文本内容
- 修改后点击保存更新内容
- 点击返回按钮放弃修改（不保存）

6.3 置顶 / 取消置顶
- 仅在首页生效
- 置顶后排序优先级最高，置于列表顶部
- 归档后的笔记保留置顶状态，但不展示、不生效

6.4 归档 / 取消归档
- 归档：笔记从首页隐藏，移入归档页面
- 取消归档：笔记从归档页返回首页
- 切换归档状态不改变笔记内容、置顶状态、创建时间

6.5 删除笔记
- 点击删除唤起二次确认弹窗
- 确认后永久删除，数据无法恢复

7. 富文本编辑器功能

7.1 支持的格式
| 功能 | 工具栏按钮 | 快捷键 |
|------|-----------|--------|
| 加粗 | B | Ctrl/Cmd + B |
| 无序列表 | • | Ctrl/Cmd + U |
| 有序列表 | 1. | Ctrl/Cmd + O |
| 删除线 | S | Ctrl/Cmd + D |

7.2 富文本存储
- 内容以 HTML 格式存储
- 读取时解析 HTML 渲染

8. 数据结构定义
```typescript
interface Note {
  id: string;           // 唯一字符串
  content: string;       // 富文本内容（HTML）
  isTop: boolean;        // 是否置顶
  isArchive: boolean;    // 是否归档
  createTime: number;    // 创建时间戳
  updateTime: number;    // 更新时间戳
}

interface NoteInput {
  content: string;       // 富文本内容（HTML）
}

interface NoteUpdate {
  content?: string;
  isTop?: boolean;
  isArchive?: boolean;
}
```
