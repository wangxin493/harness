请按以下步骤执行：

1. 用 Read 工具打开 `.harness/generated/claude.md`
2. 定位到 `## 🔥 团队经验教训` 章节，提取该章节下所有 `### [severity] 标题` 形式的条目（直到下一个 `## ` 二级标题为止）
3. 处理用户参数 `$ARGUMENTS`：
   - 若为空：原样列出该章节全部条目
   - 若有值：只保留**标题、关键词字段、适用范围、正文**任一处包含该关键词（不区分大小写）的条目；无命中则明确告知"未找到匹配经验"
4. 输出格式：保留原文档的 markdown 结构（severity 徽标、适用、关键词、正文），不要改写

特别说明：

- 这条命令存在的原因是 Agent 系统提示词在会话启动时就固化了 `.harness/generated/claude.md` 的快照；当前会话执行 `harness lesson add` 后无法即时感知，需要主动 Read 实时文件来召回最新经验
- 如果文件不存在，提示用户先跑 `harness scan` 重新生成
- 如果该章节内容是"暂无经验记录"之类的占位文字，直接告知"当前项目尚未沉淀经验教训"
