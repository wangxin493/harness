# 经验存储目录

此目录用于存储 Harness 系统的学习和经验。

## 文件类型

### patterns.json
存储代码模式和最佳实践。

### lessons-*.md
存储任务执行过程中学到的经验教训。

## 经验数据结构

### lessons 文件
```markdown
# 标题

**类别**: implementation|debugging|refactoring
**任务ID**: uuid
**时间**: ISO时间戳

## 问题
...

## 解决方案
...

## 关键点
...
```

## 用途

- 积累项目特定知识
- 提高后续任务执行效率
- 避免重复错误

## 管理

- 任务完成后自动保存经验
- 可手动添加有用经验
- 定期整理和归档
