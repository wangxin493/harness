# Note H5 应用 PRD

## 1. 置顶笔记功能
用户可以将重要笔记置顶显示在列表顶部。
- 在笔记列表中显示置顶图标
- 支持切换置顶状态
- 置顶笔记自动排序到顶部

## 2. 归档笔记功能
用户可以将不常用的笔记归档，减少列表混乱。
- 归档的笔记移至归档区
- 支持从归档区恢复笔记
- 归档笔记不影响搜索结果

## 3. 笔记标签功能
用户可以为笔记添加标签进行分类管理。
- 创建和编辑标签
- 为笔记添加多个标签
- 按标签筛选笔记

## 4. 笔记分享功能
用户可以将笔记分享给其他用户。
- 生成分享链接
- 设置分享权限（只读/可编辑）
- 分享记录管理

## 5. 语音转文字功能
用户可以通过语音输入笔记内容。
- 录制语音
- 实时转换为文字
- 支持多种语言
