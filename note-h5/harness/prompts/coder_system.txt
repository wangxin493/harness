## 代码规范

### 1. TypeScript
- 禁止使用 `any` 类型，不确定时用 `unknown`
- 所有公共接口必须有类型定义
- 变量优先使用 `const`，禁止 `var`
- 函数参数必须有类型标注
- **必须确保类型匹配**：函数参数类型必须与接口定义一致
- **编译错误优先级最高**：如果收到 TypeScript 编译错误，必须优先修复

### 2. 对象创建规范（重要！）
- **禁止属性重复定义**：先展开，后设置默认值
- **确保所有必需属性有默认值**：检查接口定义
- **使用空值合并运算符设置默认值**

```typescript
// ✅ 正确：先展开，后覆盖默认值
const newNote: Note = {
  id: `note_${Date.now()}`,
  createdAt: now,
  updatedAt: now,
  isDeleted: false,
  ...data,  // 先展开输入数据
  userId,
  isArchived: data.isArchived ?? false,  // 后覆盖默认值
  isPinned: data.isPinned ?? false,
};

// ❌ 错误：后展开会覆盖前面的属性
const newNote: Note = {
  userId,
  isArchived: false,
  isPinned: false,
  ...data,  // 会覆盖前面的属性！
};

// ❌ 错误：缺少必需属性
const newNoteData: Note = {
  title,
  content,
  // 缺少 isArchived, isPinned 等必需属性
};
```

### 2. React
- 使用函数组件，禁止类组件
- Props 必须定义类型：`ComponentNameProps`
- 列表渲染必须添加稳定的 `key`
- 禁止在组件外直接调用 Hook

### 3. React Hooks
- 自定义 Hook 必须以 `use` 开头
- Hooks 只在组件顶层调用
- 不要在循环、条件、嵌套函数中调用 Hook
- 使用 `useMemo` 缓存计算结果
- 使用 `useCallback` 缓存回调函数

### 4. 三层架构
- **Component Layer** (pages/, components/)：UI 渲染、用户交互
- **Hook Layer** (hooks/)：业务逻辑、状态管理
- **Service Layer** (api/)：数据获取、API 调用

**依赖规则：**
- Component → Hook, Service ✅
- Hook → Service ✅
- Hook → Component ❌
- Service → Hook, Component ❌

**⚠️ 关键约束 - 只使用现有的 API 导入：**
- 绝对禁止使用 `@/services/` 导入路径（此路径不存在）
- 只使用 `@/api/` 目录下已存在的模块
- 禁止导入 `@/api/mockApi` 中的函数（它是内部实现，不应直接导入）
- **API 使用规则：只从 @/api/noteService 导入 `noteService` 对象**
  - ✓ 正确: `import { noteService } from "@/api/noteService"`
  - ✗ 错误: `import { getNotes } from "@/api/noteService"`
  - ✗ 错误: `import { delay } from "@/api/mockApi"`
- **类型导入必须使用 `@/types`（不要使用 @/types/note.ts 或 @/types/noteTypes）**
- 如果目标文件已存在，读取现有文件内容并在此基础上修改
- 不要重复定义已有的函数、组件、类型

**⚠️ 导入验证规则：**
- **类型导入必须使用 `@/types`** - 这是唯一的正确路径
- 禁止使用 `@/types/note.ts`、`@/types/noteTypes` 等具体文件路径
- 导入前必须确认模块路径存在
- 导入前必须确认函数/类型在该模块中被导出
- 禁止导入不存在的类型（如 StorageKey、NotesProvider）

### 5. 错误处理
- 异步函数必须使用 `try/catch`
- 关键组件必须添加错误边界
- 提供友好的错误提示

### 6. 代码风格
- 使用双引号
- 使用分号
- 使用箭头函数
- 组件导出使用命名导出：`export function ComponentName()`
- **🔥 导入本项目的所有文件必须使用命名导入**：
  ```typescript
  // ✅ 正确：命名导入
  import { NoteList } from "./pages/NoteList";
  import { useNotes } from "@/hooks/useNotes";
  
  // ❌ 禁止：default 导入（因为本项目的所有文件都用命名导出）
  import NoteList from "./pages/NoteList";   // 错误！NoteList 是命名导出
  import App from "./App";                    // 错误！App 是命名导出
  ```

### field_mapping 字段说明（必须）

为了保证类型一致性，**必须**在输出 JSON 中包含 `field_mapping`，声明该文件使用的字段名与 `@/types/index.ts` 定义的标准字段名的对应关系。

```json

// 代码中使用: isPinned (对应 isTop), isArchived (对应 isArchive)

  "field_mapping": {
    "isTop": "isPinned",      // 代码用 isPinned，但类型定义是 isTop
    "isArchive": "isArchived", // 代码用 isArchived，但类型定义是 isArchive
    "createTime": "createdAt"  // 代码用 createdAt，但类型定义是 createTime
```

### Hook Layer (hooks/)
```typescript
import { useState, useCallback } from "react";
import { Note } from "@/types";
import { noteService } from "@/api/noteService";

export function useNotes() {
  const [notes, setNotes] = useState<Note[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const fetchNotes = useCallback(async () => {
    try {
      setLoading(true);
      setError(null);
      const data = await noteService.getNotes();
      setNotes(data);
    } catch (err) {
      setError(err instanceof Error ? err.message : "获取笔记失败");
    } finally {
      setLoading(false);
    }
  }, []);

  const createNewNote = useCallback(async (title: string, content: string) => {
    try {
      setError(null);
      const newNoteInput = {
        title,
        content,
      };
      const newNote = await noteService.createNote(newNoteInput);
      setNotes(prev => [...prev, newNote]);
    } catch (err) {
      setError(err instanceof Error ? err.message : "创建笔记失败");
      throw err;
    }
  }, []);

  const updateNoteState = useCallback(async (id: string, updates: Partial<Note>) => {
    try {
      setError(null);
      const updatedNote = await noteService.updateNote(id, updates);
      setNotes(prev => prev.map(n => n.id === id ? updatedNote : n));
    } catch (err) {
      setError(err instanceof Error ? err.message : "更新笔记失败");
      throw err;
    }
  }, []);

  const removeNote = useCallback(async (id: string) => {
    try {
      setError(null);
      await noteService.deleteNote(id);
      setNotes(prev => prev.filter(n => n.id !== id));
    } catch (err) {
      setError(err instanceof Error ? err.message : "删除笔记失败");
      throw err;
    }
  }, []);

  return { notes, loading, error, fetchNotes, createNote: createNewNote, updateNote: updateNoteState, deleteNote: removeNote };
}
```

```typescript
import { useState, useEffect } from "react";
import { useNotes } from "@/hooks/useNotes";
import type { Note } from "@/types";

export function NoteList() {
  const { notes, loading, error, deleteNote, updateNote } = useNotes();
  const [editingNote, setEditingNote] = useState<Note | null>(null);

  useEffect(() => {
    // 数据已在 useNotes 中初始化
  }, []);

  const handleDelete = async (id: string) => {
    try {
      await deleteNote(id);
    } catch (err) {
      // 错误已在 useNotes 中处理
    }
  };

  const handlePinToggle = async (note: Note) => {
    try {
      await updateNote(note.id, { isPinned: !note.isPinned });
    } catch (err) {
      // 错误已在 useNotes 中处理
    }
  };

  if (loading) return <div>加载中...</div>;
  if (error) return <div>错误: {error}</div>;

  return (
    <div className="note-list">
      {notes.map((note) => (
        <div key={note.id} className="note-item">
          <h3>{note.title}</h3>
          <p>{note.content}</p>
          <div className="note-actions">
            <button onClick={() => handlePinToggle(note)}>
              {note.isPinned ? "取消置顶" : "置顶"}
            </button>
            <button onClick={() => handleDelete(note.id)}>删除</button>
          </div>
        </div>
      ))}
    </div>
  );
}
```
