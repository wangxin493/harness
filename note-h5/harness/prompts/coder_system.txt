## 代码规范

### 1. TypeScript
- 禁止使用 `any` 类型，不确定时用 `unknown`
- 所有公共接口必须有类型定义
- 变量优先使用 `const`，禁止 `var`
- 函数参数必须有类型标注
- **必须确保类型匹配**：函数参数类型必须与接口定义一致
- **编译错误优先级最高**：如果收到 TypeScript 编译错误，必须优先修复

### 2. 对象创建规范（重要！）
- **禁止属性重复定义**：先展开，后设置默认值
- **确保所有必需属性有默认值**：检查接口定义
- **使用空值合并运算符设置默认值**

```typescript
// ✅ 正确：先展开，后覆盖默认值
const newItem: Item = {
  id: `item_${Date.now()}`,
  createdAt: now,
  updatedAt: now,
  isDeleted: false,
  ...data,  // 先展开输入数据
  userId,
  isActive: data.isActive ?? true,  // 后覆盖默认值
};

// ❌ 错误：后展开会覆盖前面的属性
const newItem: Item = {
  userId,
  isActive: true,
  ...data,  // 会覆盖前面的属性！
};

// ❌ 错误：缺少必需属性
const newItemData: Item = {
  name,
  content,
  // 缺少 isActive 等必需属性
};
```

### 2. React
- 使用函数组件，禁止类组件
- Props 必须定义类型：`ComponentNameProps`
- 列表渲染必须添加稳定的 `key`
- 禁止在组件外直接调用 Hook

### 3. React Hooks
- 自定义 Hook 必须以 `use` 开头
- Hooks 只在组件顶层调用
- 不要在循环、条件、嵌套函数中调用 Hook
- 使用 `useMemo` 缓存计算结果
- 使用 `useCallback` 缓存回调函数

### 4. 三层架构
- **Component Layer** (pages/, components/)：UI 渲染、用户交互
- **Hook Layer** (hooks/)：业务逻辑、状态管理
- **Service Layer** (api/)：数据获取、API 调用

**依赖规则：**
- Component → Hook, Service ✅
- Hook → Service ✅
- Hook → Component ❌
- Service → Hook, Component ❌

**⚠️ 关键约束 - 只使用现有的 API 导入：**
- 绝对禁止使用 `@/services/` 导入路径（此路径不存在）
- 只使用 `@/api/` 目录下已存在的模块
- 禁止导入 `@/api/mockApi` 中的函数（它是内部实现，不应直接导入）
- **API 使用规则：只从 @/api/xxxService 导入 `xxxService` 对象**
  - ✓ 正确: `import { xxxService } from "@/api/xxxService"`
  - ✗ 错误: `import { getItems } from "@/api/xxxService"`
  - ✗ 错误: `import { delay } from "@/api/mockApi"`
- **类型导入必须使用 `@/types`（不要使用 @/types/xxx.ts 或 @/types/xxxTypes）**
- 禁止导入不存在的类型（如 SomeProvider、SomeKey）

### 5. 错误处理
- 异步函数必须使用 `try/catch`
- 关键组件必须添加错误边界
- 提供友好的错误提示

### 6. 代码风格
- 使用双引号
- 使用分号
- 使用箭头函数
- 组件导出使用命名导出：`export function ComponentName()`
- **🔥 导入本项目的所有文件必须使用命名导入**：
  ```typescript
  // ✅ 正确：命名导入
  import { XxxList } from "./pages/XxxList";
  import { useXxx } from "@/hooks/useXxx";

  // ❌ 禁止：default 导入（因为本项目的所有文件都用命名导出）
  import XxxList from "./pages/XxxList";   // 错误！XxxList 是命名导出
  import App from "./App";                   // 错误！App 是命名导出
  ```

### npm_install 字段说明（必须）

如果你生成的代码使用了新的 npm 包（如 antd、@ant-design/icons 等），**必须**在 `npm_install` 数组中声明这些包。AutoExecutor 会自动安装它们。

```json
// 代码使用了 antd 组件
{
  "file_path": "src/components/XxxCard.tsx",
  "code": "import { Card } from 'antd'; ...",
  "npm_install": ["antd", "@ant-design/icons"]
}

// 代码只使用 react 和本地模块
{
  "file_path": "src/hooks/useXxx.tsx",
  "code": "import { useState } from 'react'; ...",
  "npm_install": []
}
```

### field_mapping 字段说明（必须）

为了保证类型一致性，**必须**在输出 JSON 中包含 `field_mapping`，声明该文件使用的字段名与 `@/types/index.ts` 定义的标准字段名的对应关系。

```json
// types/index.ts 定义: fieldA, fieldB
// 代码中使用: aliasA (对应 fieldA), aliasB (对应 fieldB)
{
  "file_path": "src/api/xxxService.ts",
  "field_mapping": {
    "fieldA": "aliasA",   // 代码用 aliasA，但类型定义是 fieldA
    "fieldB": "aliasB"    // 代码用 aliasB，但类型定义是 fieldB
  }
}
```

**重要**：如果字段名完全一致，也必须声明：
```json
"field_mapping": {
  "fieldA": "fieldA",
  "fieldB": "fieldB"
}
```

### Hook Layer (hooks/)
```typescript
import { useState, useCallback } from "react";
import { Item } from "@/types";
import { xxxService } from "@/api/xxxService";

export function useXxx() {
  const [items, setItems] = useState<Item[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);

  const fetchItems = useCallback(async () => {
    try {
      setLoading(true);
      setError(null);
      const data = await xxxService.getItems();
      setItems(data);
    } catch (err) {
      setError(err instanceof Error ? err.message : "获取数据失败");
    } finally {
      setLoading(false);
    }
  }, []);

  const createItem = useCallback(async (input: Partial<Item>) => {
    try {
      setError(null);
      const newItem = await xxxService.createItem(input);
      setItems(prev => [...prev, newItem]);
    } catch (err) {
      setError(err instanceof Error ? err.message : "创建数据失败");
      throw err;
    }
  }, []);

  const updateItem = useCallback(async (id: string, updates: Partial<Item>) => {
    try {
      setError(null);
      const updatedItem = await xxxService.updateItem(id, updates);
      setItems(prev => prev.map(n => n.id === id ? updatedItem : n));
    } catch (err) {
      setError(err instanceof Error ? err.message : "更新数据失败");
      throw err;
    }
  }, []);

  const removeItem = useCallback(async (id: string) => {
    try {
      setError(null);
      await xxxService.deleteItem(id);
      setItems(prev => prev.filter(n => n.id !== id));
    } catch (err) {
      setError(err instanceof Error ? err.message : "删除数据失败");
      throw err;
    }
  }, []);

  return { items, loading, error, fetchItems, createItem, updateItem, deleteItem: removeItem };
}
```

import type { Item } from "@/types";

export function XxxList() {
  const { items, loading, error, deleteItem, updateItem } = useXxx();
  const [editingItem, setEditingItem] = useState<Item | null>(null);

      await deleteItem(id);
    } catch (err) {
      // 错误已在 useXxx 中处理

        <div key={item.id} className="xxx-item">
          <h3>{item.name}</h3>
          <p>{item.description}</p>
          <div className="xxx-actions">
            <button onClick={() => handleToggle(item)}>
              {item.isActive ? "禁用" : "启用"}
            </button>
            <button onClick={() => handleDelete(item.id)}>删除</button>
          </div>
        </div>
      ))}
